# Lord Guaxi 👑

Projeto pessoal desenvolvido em C#.

Lord Guaxi é um simulador de reino em console onde o jogador administra recursos e toma decisões para desenvolver seu território.

## Funcionalidades atuais

- Sistema de dias
- Gerenciamento de recursos
- Produção de madeira
- Eventos aleatórios durante a produção
- Controle de trabalhadores

## Tecnologias

- C#
- .NET
- Visual Studio

## Próximos passos

- Mercado
- Construções
- População
- Economia
- Sistema de salvamento
- Evolução para orientação a objetos

Projeto em desenvolvimento como forma de estudo e prática de programação.
